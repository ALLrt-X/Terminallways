# TERMINALLWAYS — Этап 1: Источник и проверка данных

## Цель этапа
Надёжно получать свечи по акциям Мосбиржи (`SMLT`, `CBOM`) в `Terminallways.Core` и убедиться, что цены, время и объёмы 1-в-1 совпадают с приложением брокера.
## Шаг 1. Сбор данных с биржи
- [x] Выбрать стартовый источник:
  - *Вариант А:* `MOEX ISS` (без токенов, для истории и обкатки ядра, задержка 15 мин).
  - *Вариант Б:* Read-only API брокера (сразу реалтайм и нативные свечи).
- [x] Создать в `Terminallways.Core` базовую модель свечи (`Candle`: `Time`, `Open`, `High`, `Low`, `Close`, `Volume`).
- [x] Создать интерфейс `IMarketDataProvider`, чтобы потом безболезненно менять/добавлять источники данных.
- [x] Реализовать загрузку `1m` свечей за выбранную дату (с учётом пагинации, если свечей больше 500 за день).
- [x] Написать сборщик таймфреймов (`1m → 3m / 5m / 15m`), если источник не отдаёт `3m` напрямую.
- [x] Вывести сырой список последних 10–20 свечей в окно `Terminallways.Desktop` для визуальной проверки.
