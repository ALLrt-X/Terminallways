## Шаг 5. Реализовать модульность для добавления индикаторов
Добавить среду для написания пользовательских индикаторов

- [ ] Добавить раздел или использовать существующий для индикаторов (то что уже существует это model, это тип графика OHLCV)
- [ ] Добавить sub-интерфейсы для новых индикаторов и некоторые улучшения 
- [ ] Реализовать отдельный интерфейс стакана (если возможно ибо скорее всего требуется API брокера)
- [ ] Все настройки индикаторов на данный момент редактируются только в самих скриптах. Тратить время на реализацию настроек индикаторов в программе на данном этапе, игнорируется.
- [ ] Добавить кнопку в инструментах которая открывает окно со списком доступных индикаторов лежащих в специальной папке где хранятся их скрипты.
- [ ] Беспрепятственное не ломающее перемещение окон индикаторов, а также возможное наложение индикаторов в друг друге в одном sub-окне. (В левом верхнем углу Саб окна но не на границе а под, должна быть возможность удалить индикатор (это надпись используемого индикатора, рядом с которым будет кнопка крестик для закрытия. При закрытии индикатор удаляетса. Если это был последний индикатор, то саб панель удаляетса))
- [ ] Саб панели на данный момент могут только делить экран по вертикали.
- [ ] Чисто чиловая идея: Остальные эксперементальные панели являютса внешними как обычное окно. могут перемещатьса где угодно в программе и могут быть закрыты в любой момент так как являютса окном. Но это внутренне окно, оно идёт именно с main window, а не как отдельное.
### Критерий завершения этапа
Новые осцилляторы могут быть написаны вручную в новом подхваченном файле. Все данные успешно обновляются при динамике свечей. Экспериментальная динамика обновления свечей правильно сохраняется в памяти.
