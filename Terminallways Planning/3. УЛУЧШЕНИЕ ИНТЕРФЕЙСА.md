## Шаг 3. Добавить различные детали для улучшения удобства интерфейсом
Добавить различные удобства, чтобы можно было ещё комфортнее управлять программой.

- [x] Кнопка включения / выключения авто масштабирования по отношению к графику.
- [x] Косметическая деталь: На боковом индикаторе который указывает на текущую цену, дополнительно слева подписать выбранный инструмент актив например (SMLT 255.2)
- [x] Добавить показатель: Активная сессия / Спящая сессия. Это проверка, если рынок закрыт или открыт. Скорее всего чекаетса по обновлению, если 0 новых в течении какого то времени. Оптимизировать если выключено обновление графика каждые 3 секунды и тп
- [x] Можно добавить бар инструментария слева (при этом чтобы сделать интерфейс минималистичным можно подводить курсор к левому краю чтобы этот бар появился)
- [x] В инструментарии идут маленькие квадратные кнопки сверху вниз, это кнопки под функции инструментов конечно всё зависит от того какие есть инструменты.
- [x] Первый инструмент обычный курсор мыши ничего особенного, то есть как обычно
- [x] Второй инструмент перекрестие: Там где мы водим мышью на графике появляется перекрестие вертикальное и горзионтальное штрих пунктиром. Цвет темы можно задать в скрипту.
- [x] Третий инструмент (переключатель): В зависимости от того где находиться перекрестие можно показать информацию о баре на который он попадает (информация сверху слева в окне графика но заходит на зону появляющегося бара). В случае если включен курсор, показывает информацию только о последнем баре реальном. А если инструмент выключен, то вообще не показывает информацию (сделано для минимализма)
- [x] Экспериментальная косметика: Попробовать добавить плавное движение, скейлинг графика с затуханием движений (такая функция была в trading view и это было красиво но почему то это убрали через день). Можно выключить с помощью переменной EnablePanInertia в CandlestickChartControl.xaml.cs либо отредактировать силу инерции
### Критерий завершения этапа
Всё работает также как и до добавлений этого этапа, удобный интерфейс.
